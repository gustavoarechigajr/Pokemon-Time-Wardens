# Time Wardens

A Pokémon fan game made with Pokémon Essentials (RPG Maker XP, mkxp-z).

## Playing

* **Windows**: run `Game.exe`.
* **Android** (phones, tablets, handhelds such as the AYN Thor Max): install
  the APK from the **`android-latest`** release
  (*Releases → Time Wardens for Android (build N) →
  `TimeWardens-2.05-android.N.apk`*). The app updates itself after that, and
  devices with two screens get a DS-style touch screen with party, battle,
  map and more. See [`android/README.md`](android/README.md) for
  installing, controls and how the Android version is built.
